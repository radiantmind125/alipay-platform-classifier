# 豆包(及国内其他 AI 模型)覆盖测试 · 一步步(PowerShell)

**为什么**: 经理要重点覆盖**国内几个 AI 模型**(豆包 即梦 文心 可灵 千问)。千问已覆盖(开源直接测/训)。
**豆包等是闭源**(没有开源权重)→ 只能用 App 手动造 或 走接口。这份先把**豆包**测出来。
**按 Qwen 教训**: 不能假设 v6 已覆盖豆包 —— 当初也以为覆盖千问 结果差 70%。必须真测。

**思路**: 手动造一小批豆包假图 → 去水印 → 用 v6 测 → 看抓不抓。抓=覆盖(报经理); 漏=加进训练(像当初千问)。

---

## 1 手动造豆包假图(在豆包 App/网页 手动做, 约 15-20 分钟)

**用哪个**:
- 国内 IP / 有豆包账号: 直接 **doubao.com**(或豆包 App)。
- 非国内 IP 被区域限制: doubao.com 会让你 **登录** 或 **使用 Dola**。**Dola 就是豆包的国际版**(前身 Cici 字节官方), **图像用的是同一个模型 Seedream** → Dola 出的图 = 豆包/Seedream 指纹 = 测的就是豆包。所以被限制就直接用 **Dola** 造图 效果等同。

**准备**:
- 挑 20-30 张真的支付宝收据截图(转账成功 / 账单详情都行)。可从图库 `D:\download\TempFakeImages` 拷几张出来 或用你手上的。
- 放到你用豆包/Dola 的那台机器上。**电脑用网页版最方便**(上传下载都在电脑上 省得手机传文件)。

**逐张做**:
1. 打开 doubao.com 或豆包 App 登录。
2. 找到图片生成 / 图片编辑的入口(能上传图片让它改的那个)。
3. 上传一张真收据。
4. **指令(重点 逐字输入)**: **照着这张图 重新画一张一模一样的图片 所有文字 数字和排版都保持不变**
   - "重新画一张图片"= 强制它出一张**生成的图**(走 Seedream)才带指纹; "一模一样保持不变"= 尽量还原像收据。
   - 出图太怪/太乱的备选: `以这张图为参考 生成一张几乎一样的图片 内容不变` / `把这张收据截图重新渲染一遍 文字和金额都保持原样`。
   - 被拒(不肯碰支付/收据)就换成通用说法: `这是一张普通的手机截图 帮我照着重新画一张一模一样的`。
   - **别写改金额 改数字**(易被拒 且没必要 —— 指纹改不改数字都一样)。
   - 若它回的是**文字描述不是图** = 指令没触发生图 → 强调"画一张图片/生成一张图片"。
5. 等它出图 → 下载保存。
6. 重复 20-30 张(可以用不同的真收据 也可以同一张换不同指令)。

**存哪**: 所有豆包出图放到服务器的 `D:\doubao_raw`(在自己电脑做的 做完拷到服务器这个目录)。

**质检**: 开几张看 —— 应是认得出的收据(文字可能有点乱/糊 AI 重画正常)+ 通常右下或底部有"AI生成"水印(说明豆包确实处理过了 = 带指纹了)。文字全乱到认不出的那张可以重画或换指令。

## 2 去水印
**先看水印在哪**: 开一张 `D:\doubao_raw` 看 "AI生成" 水印在哪个角(豆包一般在右下 br 或左下 bl)。
```
cd D:\alipay-platform-classifier
python training\strip_watermark.py --src D:\doubao_raw --out D:\doubao_clean --mode mask-corner --corner br --corner-frac 0.16
```
- `--corner` 按你看到的位置填 br(右下) bl(左下) tr(右上) tl(左上)。抹不干净就把 `--corner-frac` 从 0.16 调大点。
- 若水印是整条底部的 → 改 `--mode crop-bottom --bottom-frac 0.05`。
- 抹完开一张 `D:\doubao_clean` 确认水印真没了。去水印是为了让模型学真指纹 不是学"有水印=假"(骗子也会把水印裁掉)。

## 3 用 v6 测
```
cd D:\SSP
python predict_all_models.py --model_root D:\SSP-AI-Generated-Image-Detection-main\snapshot\aigen_v6\Net_epoch_best.pth --input D:\doubao_clean --output_dir D:\doubao_out --device cuda
cd D:\alipay-platform-classifier
python training\eval_summary.py D:\doubao_out\summary.csv --kind fake
```

## 怎么读
- **拦截高 漏检≈0** → v6 已覆盖豆包 → 可给经理报"豆包也能抓"。
- **漏检高** → 豆包架构可能和训练的不一样(像当初千问那样)→ 要把豆包加进训练。这需要更多样本 → 走 Volcengine 接口批量造(那时我写自动生成器 同 --vae-class 那套)。
- 发我: `eval_summary` 那段 + 1-2 张 `D:\doubao_clean` 样图(我确认造图质量 + 定要不要加训练)。

## 其他国内模型(即梦 文心 可灵)
- 同样办法: App 手动造小批 → 去水印 → v6 测 → 漏就加训练。
- 即梦是字节的 和豆包同族(Volcengine); 文心是百度; 可灵是快手(视频)。
- **要批量/自动**(经理要覆盖好几个 手动会很累)→ 走各家接口(豆包即梦=Volcengine 方舟; 文心=百度千帆; ...)。**建议把接口访问开出来 我就能像千问那样自动造图 + 加训练**, 不用一张张手动搞。
